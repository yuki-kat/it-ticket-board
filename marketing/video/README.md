# Binboard launch videos

Source for the promo videos and their audio, all 1920×1080: a 60-second sales video, a 34-second open-source showcase, and a 1:41 guided tour (`record-tour.mjs`, music section `tour`). Everything on screen is sample data, and the escalation workbook is the made-up test fixture.

| Folder | What's in it |
| --- | --- |
| `record/` | Playwright scripts that drive the built `index.html` and record each video, with captions, title cards and a cursor drawn into the page |
| `audio/music3.py` | Original launch-trailer music, generated in code with no samples, so there's nothing to license. The chords change and the hits land on each video's scene cuts |
| `audio/vo.py` | Narration with the Kokoro-82M voice (Apache-2.0). Places each line on its scene, lowers the music under the voice, normalises to -14 LUFS and checks the wording with speech-to-text |
| `text/` | The narration script, and lyric sheets for making a song version in Suno |

Generated files go in `work/` (git-ignored): recordings, music, the voice model and the finished videos.

## Setup

1. Build the board and install the test tools, as for the browser tests: `cd app && npm ci && npm run build:page`, then `cd ../tests && npm ci`.
2. Make a Python environment for the audio:
   ```bash
   python3 -m venv marketing/video/work/venv
   marketing/video/work/venv/bin/pip install numpy kokoro-onnx faster-whisper imageio-ffmpeg
   ```
   `imageio-ffmpeg` brings an ffmpeg with libx264. Point `FFMPEG` at it, or use any ffmpeg on your `PATH`.
3. The voice step downloads its model from huggingface.co, so that host has to be reachable.

## Make the videos

Run these from the repository root.

1. **Record** each video. The script saves a `.webm` and a `marks.json` of scene times:
   ```bash
   node marketing/video/record/record-sales.mjs "$PWD/index.html" "$PWD/tests/fixtures/escalation-matrix-sample.xlsx" marketing/video/work/sales-take
   node marketing/video/record/record-oss.mjs "$PWD/index.html" "$PWD/tests/fixtures/escalation-matrix-sample.xlsx" marketing/video/work/oss-take
   ```
   The open-source and tour recorders serve the board on 127.0.0.1:4192 and stand in for the AI API themselves. The tour is recorded the same way (`record-tour.mjs`, encoded with `-t 100.7`). Record it from a build that includes the Kanban card fix (PR #98).
2. **Encode** at full HD: drop the first 1.5 seconds of browser start-up, scale up from 1440×810 and add a silent track. For the sales video:
   ```bash
   ffmpeg -ss 1.5 -t 60.04 -i marketing/video/work/sales-take/*.webm -f lavfi -i anullsrc=r=48000:cl=stereo \
     -map 0:v -map 1:a -vf "scale=1920:1080:flags=lanczos" -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p -r 25 \
     -c:a aac -b:a 96k -shortest -movflags +faststart marketing/video/work/sales-video/Binboard-sales-60s.mp4
   ```
   The open-source video is the same with `-t 33.6`, saved as `oss-video/Binboard-open-source-30s.mp4`.
3. **Music:**
   ```bash
   marketing/video/work/venv/bin/python marketing/video/audio/music3.py sales marketing/video/work/audio/bed3-sales.wav
   marketing/video/work/venv/bin/python marketing/video/audio/music3.py oss marketing/video/work/audio/bed3-oss.wav
   ```
   Scene cut times are set in `SECTIONS` and `HITS` near the top. If a new recording changes the timing, list the cuts with `ffmpeg -i video.mp4 -vf "select='gt(scene,0.25)',showinfo" -f null -` and update them.
4. **Narration and mix:**
   ```bash
   cd marketing/video
   work/venv/bin/python audio/vo.py fetch af_heart am_michael
   work/venv/bin/python audio/vo.py render af_heart
   work/venv/bin/python audio/vo.py check af_heart
   ```
   - `render` writes `*-voiced-af_heart.mp4` next to each video. It prints where each line starts and flags any line that runs past its scene.
   - `check` transcribes the narration and lists any word that differs from the script.
   - `am_michael` is the male alternative.
   - The scene times and script lines are in `VIDEOS` in `vo.py`.

Listen to every voiced video in full before it's published.
