# Legacy copy of the old page

`index-compiled-2026-09-26.html` is the ticket board as it was **before** `index.html` was built from the React source (`app/`): a compiled React bundle plus about 25 add-on scripts.

It is here so you can open the old and the new page next to each other and compare them with your own saved data. Both keep their data in the same browser storage under the same names, so they see the same tickets and assets.

Nothing uses this file, and it is not tested or updated. Delete this folder once you are happy with the new page. The old version also stays in git history (commit `fbebdca` and earlier).
