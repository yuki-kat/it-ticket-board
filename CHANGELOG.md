# Changelog

All notable changes to IT Ticket Board are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-28

### Added
- **Global Search** — Full-text search across tickets with filter controls (status, severity, assignee, requester, record type)
- **Sortable Results** — Click column headers to sort by ID, title, status, severity, assignee, requester, or created date
- **Search Navigation** — Accessible via new Search tab in the main navigation
- **Responsive Layout** — Adapts to mobile, tablet, and desktop screens

### Changed
- Restructured project metadata for public release (name, version, description, keywords)
- Enhanced README with feature highlights, quick-start guides, and architecture overview
- Added MIT License file for proper open-source attribution

### Fixed
- Improved browser compatibility for modern Chrome, Firefox, Safari, and Edge

## [Unreleased]
